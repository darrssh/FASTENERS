# 7. REALISTIC METALLIC BOLT — MODELING REQUIREMENTS

Create or source a high-quality 3D hex bolt model.

The bolt must include:

1. A realistic hexagonal head.
2. Properly beveled head edges.
3. A cylindrical shaft.
4. A clearly defined threaded section.
5. Realistic thread geometry.
6. A believable transition between the smooth shaft and threaded region.
7. Appropriate proportions.
8. Accurate metallic shading.
9. Realistic surface reflections.
10. Separate geometry or objects where required for animation.

The bolt must look like a real manufactured fastener.

Do not use a low-quality generic bolt model.

Do not fake the threads using a simple spiral texture.

Use actual thread geometry for the primary hero model if performance allows.

If the full thread geometry is too expensive, use an optimized model with convincing thread geometry and appropriate level-of-detail techniques.

The thread must remain believable in close-up shots.

## GEOMETRY QUALITY

Use realistic bevels.

Avoid perfectly sharp, mathematically hard edges.

Use proper normals and smoothing.

The hexagonal head must have recognizable flat faces.

The shaft must have correct proportions.

The thread profile must resemble a real industrial thread.

Do not exaggerate the thread depth.

Avoid visible polygonal artifacts.

Do not allow the model to appear melted, distorted, or asymmetrical unless the real product requires it.

Use the following lighting structure:

A large, soft light source above and to one side of the bolt.

## FILL LIGHT

A softer light source on the opposite side.

Purpose:

* Reveal details in darker areas.
* Preserve the shape of the product.
* Prevent excessive black regions.

## RIM LIGHT

A light source behind the bolt.

Purpose:

* Separate the bolt from the dark background.
* Create a subtle metallic edge highlight.

## ACCENT LIGHT

Use a subtle blue accent light.

Purpose:

* Connect the product to the visual identity.
* Add a small amount of visual depth.

## SHADOWS

Avoid harsh, unnatural shadows.

25%–42%
